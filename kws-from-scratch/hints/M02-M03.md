# M2、M3 提示：音频 I/O 与特征

## 1. `pad_or_crop` 的三种模式写得很乱

<details><summary>提示 1</summary>

“补”和“裁”其实是同一个问题：要算出一个偏移量。补的时候，偏移量是“原信号放在新数组的哪个位置”；裁的时候，偏移量是“从原信号的哪个位置开始取”。两种情况下偏移量的取值范围都是 `[0, |T - num_samples|]`。

</details>

<details><summary>提示 2</summary>

先算差值 diff，再按 mode 算 offset（0、diff // 2、或者随机），最后分两路：裁用切片 `wav[..., offset:offset + n]`，补用 `torch.nn.functional.pad(wav, (左, 右))`。`...` 让前面的维度原样保留。

</details>

## 2. `frame_signal` 不知道怎么不写循环

<details><summary>提示 1</summary>

查 `Tensor.unfold(dimension, size, step)`。

</details>

<details><summary>提示 2</summary>

center=True 时先用 `F.pad(..., mode="reflect")` 两端各补 n_fft // 2。注意：reflect 模式对输入的维数有要求（查文档），一维输入可能需要先临时加维度，补完再去掉。

</details>

## 3. `power_spectrogram` 和 torch.stft 对不上

<details><summary>提示 1</summary>

逐项检查：窗函数是不是 periodic 的？是否在两端做了 reflect 补齐？输出的维度顺序是 (频率, 帧) 还是 (帧, 频率)？

</details>

<details><summary>提示 2</summary>

分帧 → 乘窗 → `torch.fft.rfft(..., dim=-1)` → `.abs() ** 2` → 交换最后两维。

</details>

## 4. `mel_filterbank` 和 torchaudio 对不上

<details><summary>提示 1</summary>

FFT 频点的频率是怎么取的？torchaudio 用 `linspace(0, sample_rate // 2, n_freqs)`。Mel 点是在 Mel 刻度上等距取 n_mels + 2 个，再换回 Hz。

</details>

<details><summary>提示 2</summary>

每个三角形由三个相邻的 Hz 点（左 f[m]、顶 f[m+1]、右 f[m+2]）决定。某个频率 x 的高度 = max(0, min(上升边, 下降边))，上升边 = (x - 左) / (顶 - 左)，下降边 = (右 - x) / (右 - 顶)。

</details>

<details><summary>提示 3</summary>

不要写双重循环：把 n_freqs 个频率排成列向量，把 n_mels + 2 个 Mel 点（换算回 Hz 后）排成行向量，相减得到 (n_freqs, n_mels + 2) 的差值矩阵。再用切片取出每个三角形的“左”和“右”两列，算上升边和下降边，逐元素取较小值，最后把负数夹成 0。

</details>

## 5. `LogMelSpectrogram` 的输出数值差很多

<details><summary>提示 1</summary>

功率谱是 (B, n_freqs, n_frames)，滤波器组是 (n_freqs, n_mels)。矩阵乘法时哪两维要对齐？乘完的 shape 对吗？

</details>

<details><summary>提示 2</summary>

先确认 power_spectrogram、mel_filterbank、power_to_db 三个函数各自的测试都过了，再查组合。问题通常出在维度转置上。

</details>
