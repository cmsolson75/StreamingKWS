把命令行分成两部分

目标：自己完成训练入口的 parse_args，让调用者拿到配置路径和覆盖参数。

["--config", "c.yaml", "train.lr=0.01"]
                  ↓
("c.yaml", ["train.lr=0.01"])

先只注册 --config。剩下的字符串原样交给后续配置逻辑处理。

先认识工具

import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--config", required=True)
args, remaining = parser.parse_known_args(
    ["--config", "c.yaml", "train.lr=0.01"]
)

args 是按属性访问结果的 Namespace；remaining 是解析器没有处理的字符串列表。普通 parser.parse_args 默认会因这些未注册的额外参数报错。

预测，再展开核对

上面代码执行后，args.config 和 remaining 分别是什么？

核对
args.config == "c.yaml"
remaining == ["train.lr=0.01"]

配置路径被取出，覆盖参数仍是字符串。

如果传入的列表只有 train.lr=0.01，会得到什么？

核对

缺少 required=True 指定的 --config，默认报错并触发 SystemExit。这也对应项目的第二个测试断言。
